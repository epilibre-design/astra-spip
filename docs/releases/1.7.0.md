# Astra SPIP 1.7.0

Publication du 26 octobre 2026, sur la référence WordPress Astra 4.13.8.

## Nouveautés

- **Identité responsive** : tailles et visibilité du nom du site et du slogan, largeur du logo,
  sur ordinateur, tablette et mobile. Les valeurs déjà enregistrées sont prises en compte ;
  le formulaire permet de régler les trois appareils. La définition de l’image est conservée
  lorsqu’un appareil demande un logo plus large.
- **Widgets du pied** : alignement du texte des quatre zones sur les trois appareils,
  avec les options `footer-widget-alignment-1` à `footer-widget-alignment-4`.
- **Commentaires** : utilisation facultative du plugin SPIP Gravatar 3.x, avec repli sur
  l’initiale lorsque le plugin ou l’image est indisponible.

Ces fonctions proviennent des PR [#23](https://github.com/epilibre-design/astra-spip/pull/23)
et [#24](https://github.com/epilibre-design/astra-spip/pull/24), déjà intégrées à `main`.
Cette publication les rend accessibles sous un tag distinct de `v1.6.0`.

## Installation et mise à jour

Utiliser le tag **`v1.7.0`** et activer ou mettre à jour Astra dans SPIP. Le schéma reste
à 1.0.0, sans migration de base de données. Le statut du plugin reste `test` et la plage de
compatibilité déclarée reste SPIP 4.2 à 5.0 ; cette publication ne constitue pas une nouvelle
qualification exhaustive de cette plage. Gravatar est facultatif et n’est pas installé
automatiquement ; sa version 3.x ne s’active pas sous SPIP 5.

Pour Garden, la consommation de cette version et les quatre réglages d’alignement feront
l’objet du prochain lot. La publication d’Astra ne modifie pas les réglages du site Garden.

## Limites conservées

La navigation de secours sans JavaScript peut recouvrir le titre sous un en-tête transparent ;
à 922 px sans JavaScript, le menu d’en-tête peut être absent. Ces défauts relevés par la
[recette Garden](https://github.com/tech-nova/garden-spip/pull/13) restent à corriger.

Les qualifications détaillées des fonctions sont conservées avec leurs sources et limites :
[identité responsive](../inventaires/identite-responsive/bilan.md),
[alignements des widgets](../inventaires/widgets-alignements/bilan.md),
[Gravatar](../inventaires/gravatar-commentaires/bilan.md).

## Vérification de publication

Sur une installation SPIP 4.4.28 isolée, sous PHP 8.4.27 et PHPUnit 11.5.57 :

- 190 tests unitaires, 2065 assertions, sans échec ;
- 110 cas d’intégration, dont 104 exécutés et 6 ignorés, 653 assertions, sans échec ;
- 28 cas Python, dont 27 exécutés et 1 ignoré, sans échec ;
- syntaxe des 181 fichiers PHP versionnés valide sous PHP 7.4.33.

Les six cas d’intégration ignorés nécessitent les installations dédiées Gravatar et oEmbed ;
leur qualification reste celle du bilan Gravatar ci-dessus et de la
[référence oEmbed](../../tests/fixtures/oembed/README.md). Le cas Python ignoré nécessite l’archive
privée R0 d’Astra 4.11.0. Les tests de définition du logo responsive ont été exécutés avec
les images dimensionnelles prévues. Les captures visuelles historiques ne sont pas relancées
pour cette publication : le code fonctionnel reste celui de `05dc563`.

Le manifeste passe de 1.6.0 à 1.7.0 ; les autres changements de publication sont documentaires.
Les [compteurs et empreintes des contrôles](1.7.0-validation.json) identifient cette passe.
